# ミクスチャー・サークル

**カードを出すたびに楽器が加わり、みんなで1曲を作る音楽カードゲーム。**

3〜6人が円になって座り、手番なしで好きなときにカードを箱へ入れる。
箱がカードを読み取ると、次の拍から音が加わる。勝敗はない。

👉 **[ブラウザで遊ぶ（GitHub Pages）](https://jinkinokino5-max.github.io/mixture-circle/)**

---

## 5つのプロトタイプ

同じ企画を5回作り直した記録です。どれも独立して動きます。

| | 版 | カードの構造 | 枚数 | 音源 | 初回の読み込み |
|---|---|---|---|---|---|
| [Phase 0](output/phase0-app/) | 最初の版 | 楽器 × ジャンル | 24 | 合成音 | ほぼ0MB |
| [STUDIO](output/studio-app/) | 実録音の導入 | 楽器 × ジャンル | 24 | 実録音 | 約10MB |
| [v2](output/studio-app-v2/) | 役割の導入 | **役割** × ジャンル | 20 | 実録音 | 約17MB |
| [v3](output/studio-app-v3/) | 手ごたえの作り直し | 役割 × ジャンル | **32** | 実録音 | 約39MB |
| [v4](output/studio-app-v4/) | ジャンルの撤廃 | 役割 × **楽器** | 32 | 実録音 | 約26MB |

各アプリのフォルダに、設計の意図と実測した確認結果を書いた README があります。

## 遊びかた

キーを押すか、画面のマスをクリックすると音が加わります。
キーボードの並びが、そのまま画面のグリッドです。

- `Backspace` … 最後に入れた音を消す
- `Esc` … 終了して録音を書き出す
- スマホ・タブレットでもタップで遊べます

## なぜ何を重ねても破綻しないのか

1. **調を固定**しているので、何を重ねても音が外れない
2. 役割ごとに**音の高さの居場所**を分けてある
3. 音が入るのは**次の拍（または小節）の頭**。ズレた音が混ざらない
4. 同時に鳴る数に上限があり、古い音から抜けていく

## ローカルで動かす

`はじめる.bat` をダブルクリックすると簡易サーバが立ち、ブラウザが開きます（Python か Node.js が必要）。
音源はリポジトリに含まれているので、`音源をダウンロード.bat` は基本的に不要です。

## 物理カードについて

物理カードとRFIDリーダーによる読み取りは準備中です。
各アプリの `cards.js` に、リーダーが届いたらカードIDを登録するだけで動く仕組みが入っています。
