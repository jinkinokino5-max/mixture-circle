## 2. Day 1：耳で聴いて音を決める（最優先・半日〜1日）

**これをやらないと先に進めない。** 数字上は全部鳴っているが、音楽として成立しているかは未検証。

### 2-1. 手順

1. `はじめる.bat` → BPM 96・無制限で起動
2. **単体で聴く**：20枚を1枚ずつ入れて、基礎ビートと2枚だけの状態で音を確かめる
3. **ジャンル内で揃えて聴く**：同じジャンルの4役割（例：ジャズの `2` `W` `S` `X`）を全部入れる
   → これが「そのジャンルらしく聞こえるか」の基準になる
4. **ジャンルを混ぜて聴く**：ロックのドラム＋ジャズのベース＋クラシックのメロディ など
   → これが本番の遊び方。**ここが破綻していなければ設計は成功**

### 2-2. 直す場所（`app.js` の上のほうだけ見ればよい）

| 気になったこと | 触る場所 |
|---|---|
| ある楽器だけ大きい／小さい | 各カードの `gain`（dB） |
| ベースがこもる／メロディが刺さる | `ROLES` の `hp` / `lp` |
| 音域が高すぎる／低すぎる | 各カードの `oct` |
| フレーズが単調・くどい | `CARDS[...].phrase`（小節を足す／減らす） |
| ジャンルらしくない | そのカードの `phrase` を書き直す |
| ドラムの音が合わない | `kit` を差し替え（`acoustic-kit` / `Kit3` / `breakbeat13` / `CR78` / `LINN` / `Techno` がDL済み） |

### 2-3. 完了の目安

- [ ] 6パート重ねても、どれか1つが極端に目立つ／埋もれる状態にならない
- [ ] ジャンルを混ぜても不快でない（＝「破綻しない濁り」になっている）
- [ ] 各ジャンルが「言われれば分かる」程度には性格づけされている

## 3. Day 2：ROLE をルールに効かせるか決める（半日）

**Day 1 で実際に鳴らしてから判断する。** 判断材料は「同じ役割が重なったときに濁るか」。

### 3-1. 実際に試すこと

| 試す組み合わせ | 見たいこと |
|---|---|
| BASS を2〜3枚同時 | 低域がぶつかって濁るか。濁るなら BASS は同時1枚に制限する |
| RHYTHM を3枚以上同時 | 拍が混線して聞こえるか |
| MELODY を4枚同時 | 主旋律が複数あって「顔」が無くなるか |
| CHORD だけ4枚 | 和音が厚すぎて潰れるか |

### 3-2. 判断の選択肢

| 案 | 内容 | 向いている場面 |
|---|---|---|
| **A. 何もしない**（現状） | ROLE は音の役割だけ。ルールは6パート上限のみ | 濁っても不快でなければこれが最善。ルールが増えない＝設計思想に忠実 |
| **B. 役割ごとに上限** | 例：BASS は同時1枚、RHYTHM は2枚まで | 特定の役割だけが破綻する場合 |
| **C. 押し出しの優先順位** | 7枚目で「最古」ではなく「同じ役割の中で最古」を抜く | 役割の偏りが問題になる場合 |

> 設計思想（`reference/アイデア2.txt`）は「カードの種類を増やしても基本操作は増やさない」。
> **迷ったら A（何もしない）を選ぶ。** ルールを足すのは、実際に破綻したときだけ。

### 3-3. 完了の目安

- [ ] 上の4パターンを実際に鳴らして聴いた
- [ ] A / B / C のどれにするか決め、決めた理由をこのファイルに追記した

## 5. Day 4以降：物理化（リーダー到着後）

既存の `draft/ロードマップ_到着までの1週間.md` の手順がそのまま使える。
**v2 で変わるのは次の2点だけ。**

1. **枚数が 24 → 20 枚**
2. **カードIDの書式が変わった**
   - v1 `<ジャンル>-<楽器>` 例 `jazz-piano`
   - v2 `<ジャンル>-<役割>` 例 `jazz-chord`
   - → `cards.js` に20枚ぶんの雛形をコメントで用意済み。UIDを控えてコメントを外すだけ

### 5-1. 手順

1. メモ帳を開いてNFCシールをかざし、打ち込まれるUIDを控える（20枚ぶん）
2. `output/studio-app-v2/cards.js` の `CARD_MAP` にUIDを書く
3. `はじめる.bat` で起動し、カードを投入口に入れて読み取りを確認

### 5-2. 完了の目安（Phase 1 の DoD）

- [ ] カードを投入口に入れると95%以上の確率で1回で読み取れる
- [ ] 同じカードを2回入れても音が二重にならない（実装済み・500msガード）
- [ ] 制限時間で自動的に終わり、余韻を残して止まる（実装済み）
- [ ] PCを繋いで5分以内にセットアップできる
- [ ] 20枚のカードが物理的に完成し、UID登録済み

## 6. カードの意匠について（今回のスコープ外）

印刷用カードは今回作っていない（`cards-print.html` は v2 には無い）。
作るときに決めることだけ書いておく。

- **表記**：`reference/アイデア2.txt` の基本表記は「役割（大）／楽器（小）」の2段
  - 例：`MELODY` ＋ `Saxophone`
  - v2 はこの構造そのものなので、そのまま印刷できる
- **色**：ジャンルで色を分ける（アプリ内の色と揃える）
  - ロック＝赤黒／ジャズ＝深い青／クラシック＝白金／エレクトロ＝ネオン／ポップ＝明るいピンク
- **判別**：役割を形（アイコン）で、ジャンルを色で分けると、暗い場所でも見分けやすい
