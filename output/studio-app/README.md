# ミクスチャー・サークル STUDIO — 本格音源版

Phase 0 版（`output/phase0-app`）とは**別の、もう一つのアプリ**。
ゲームの仕組みは同じまま、音だけを「実際に録音された楽器の音」に差し替えたもの。

| | Phase 0 版 | STUDIO 版（これ） |
|---|---|---|
| ピアノ・ギター・ベース・ブラス・ドラム | 合成音 | **実録音サンプル** |
| シンセ | 合成音 | **合成音のまま**（シンセはシンセの音であるべきなので） |
| ネット接続 | 不要 | **最初の1回だけ必要**（音源の取得） |
| 起動方法 | `index.html` 直開きでも可 | **`はじめる.bat` 必須**（音源の読み込みにサーバが要る） |
| ポート | 8765 | 8766（同時に両方立ち上げられる） |

カードID・キー配置・`cards.js` の書式は Phase 0 版と完全に互換。
印刷済みカードと `cards-print.html` はそのまま使える。

## 使い方

1. **`音源をダウンロード.bat`** をダブルクリック（**最初の1回だけ**・約9.5MB・要ネット接続・要 Node.js）
2. **`はじめる.bat`** をダブルクリック → ブラウザが開く
3. 開始画面に「本格音源 88 個を読み込みました」と出たら準備完了
4. あとは Phase 0 版と同じ。キーを押すと次の拍頭から音が加わる

音源を落とさずに始めることもできる。その場合は全パートが合成音になる（＝Phase 0 版と同じ音）。

## 音を調整したいとき

`app.js` の上のほうだけ見ればよい。

- `INSTRUMENTS` … 楽器ごとの **音量（`gain`, dB）**・帯域（`hp`/`lp`）・オクターブ・サンプラーの `env`
- `GENRES` … リズムパターンと、`gtr`（ギター音源）・`kit`（ドラムキット）・`drive`（歪み）
- `BASE_KIT` … 基礎ビートのキット

**音量バランスが気になったら `gain` を触る。** 実録音は音源ごとに録音レベルが違うので、
ここは実際に聴きながら合わせるのが前提の値になっている（今の値は未調整の初期値）。

ドラムキットは `acoustic-kit` / `Kit3` / `breakbeat13` / `CR78` / `LINN` / `Techno` を
ダウンロード済みなので、`GENRES[*].kit` の文字列を書き換えるだけで差し替えられる。

## 動作確認済みのこと

Chrome で実際に起動して確認した。

- 音源88個の読み込み（エラーなし）
- ピアノ・ギター・ベース・ブラス・ドラムが `Tone.Sampler`（実録音）で鳴ること
- シンセだけが `PolySynth`（square 波・合成音）のままであること
- 基礎ビート＋6パートを重ねて実際に音が出ていること（マスター出力を実測）
- 同時6パート上限と、7つ目投入時に最古が抜けること
- 同じカードの二重投入が無視されること
- 終了時に録音が再生・保存できること

**未確認：** 音量バランスと音色の善し悪し（実際に耳で聴く必要がある）。
