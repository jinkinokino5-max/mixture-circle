# STUDIO PULSE II — 音と楽器を詰めた版（studio-app-v5）

v4（ROLE × INSTRUMENT）の**骨格はそのまま**に、
「**どんな音と楽器を用意すれば気持ちよくセッションできるか**」だけを追求した版。

カードは v4 と同じく **ROLE（曲の中で何をするか）× INSTRUMENT（何の音でするか）** の2軸。
調・コード進行・グルーヴをエンジンが握るので、何と何を重ねても必ず噛み合う——という前提も同じ。

---

## 1. 使い方

1. **`音源をダウンロード.bat`** を最初に1度だけ実行（インターネット接続が必要／約43MB）
2. **`はじめる.bat`** をダブルクリック → ブラウザが開く（ポート **8770**。v4 は 8769 なので同時に動かせる）
3. 「はじめる」を押して、キーボードでカードを重ねる

※ `index.html` を直接ダブルクリックしても動くが、ブラウザの制限で音源が読めず全パート合成音になる。必ず `はじめる.bat` から開く。

---

## 2. v4 から変えたこと（要点だけ）

| # | 変えたこと | なぜ |
|---|---|---|
| 1 | **ドラムの語彙を増やした**（クラッシュ／ライド／オープンハット／タム3種） | v4 は kick / snare / hihat / tom1 の4つしか無く、「小節頭の開放感」「拍の伸び」が出せなかった。ここが叩いてる感にいちばん効く |
| 2 | **楽器を 13 → 20 種類に**（カード 32 → 40 枚） | 手数が足りなかった。特に中低域（トロンボーン・バスーン・チューバ・クラリネット）と、面で支える音（ハルモニウム・ホルン）が空白だった |
| 3 | **4小節目だけパターンが変わる**（`patB` / `drumB`） | v4 は1小節ループの繰り返しで、入れっぱなしにすると景色が動かなかった |
| 4 | **RHYTHM を同時3枚まで**／キック無しの「薄い層」を 2 → 4 枚に | 積み上げる快感はここから来る。重ねても土台が濁らない層が足りなかった |
| 5 | **音源のラウドネスを実測して自動でそろえる** | v4 の `gain` は「音楽的な存在感」と「録音レベルの差」の両方を背負っていて、楽器を1枚足すたびに全部を耳で取り直す必要があった |

## 3. 操作

| 操作 | 内容 |
|---|---|
| `1`〜`0` | MELODY（曲の顔）10枚 |
| `Q W E R T Y U I O P` | CHORD（曲の空間）10枚 |
| `A S D F G H J K L ;` | BASS（曲の足元）10枚 |
| `Z X C V B N M , . /` | RHYTHM（曲の動き）10枚 |
| **スペース** | **ビルドアップ＆ドロップ**（2小節かけて持ち上げ、次の小節頭でクラッシュとともに落とす） |
| `↑` `↓` | ENERGY（静／走／熱） |
| **`Tab`** | コード進行を切り替え（夜／陽／呪／都）※v4 は `P` だったが、`P` がカードになったため移動 |
| `Backspace` | 最後に入れた1枚を戻す |
| `Esc` | 終了（録音を書き出す） |
| クリック | カード投入。**同じカードをもう一度押すと止まる** |

同時に鳴らせる枚数：**MELODY 2 / CHORD 2 / BASS 1 / RHYTHM 3**。
上限を超えると、その ROLE のいちばん古い音と自動で交代する。

## 4. カード一覧（40枚）

### MELODY（曲の「顔」・同時2枚）
ピアノ／エレキギター／**ナイロンギター**／サックス／**クラリネット**／フルート／ヴァイオリン／トランペット／**トロンボーン**／シンセリード

### CHORD（曲の「空間」・同時2枚）
ピアノ／アコギ／カッティング／オルガン／**ハルモニウム**／ハープ／ストリングス／ブラス／**ホルン**／シンセパッド

### BASS（曲の「足元」・同時1枚）
エレキベース／ウッドベース／チェロ／**チューバ**／**バスーン**／オルガンベース／ピアノ（低音）／シンセベース／ファズベース／サブベース

### RHYTHM（曲の「動き」・同時3枚）
| キック持ち（土台になる・6枚） | 薄い層（キック無し・どれにでも重ねられる・4枚） |
|---|---|
| 生ドラム／ブレイクビーツ／四つ打ち／ドラムマシン／80sマシン／**ロックキット** | 木琴／シェイカー／**ボンゴ**／**ライド** |

**太字**が v5 で追加した楽器。シンセ系5枚（シンセリード／シンセパッド／シンセベース／ファズベース／サブベース）以外はすべて**実録音**。画面の各カード右上に「実録音／合成音」が出る。

## 5. ドラムの語彙（v5 で足した部分）

`music.js` の `drum` に書ける項目：

| 記号 | 意味 | 効果 |
|---|---|---|
| `k` `s` `h` | キック／スネア／ハイハット | v4 から |
| `t` `t2` `t3` | タム（高→低） | フィルが「下りていくタム回し」になる |
| `oh` | オープンハイハット | 裏拍が伸びて前へ押される |
| `rd` | ライド | 刻みが金物になり、音数を増やしても濁らない |
| `cr` | クラッシュ | `bar % crEvery === crPhase` の小節だけ。小節頭で「開ける」 |
| `h3` `ghost` | ENERGY 3 の裏／小さいスネア | v4 から |

クラッシュ／ライド／オープンハットは**公開音源側に1枚も存在しない**ため、`samples.js` の `makeCymbals()` が `Tone.MetalSynth` で合成している（`tom2` `tom3` は実録音）。

## 6. 音量バランスの決め方（v5 の考え方）

読み込みが終わった時点で、`samples.js` が全バッファのラウドネスを実測する。

- 測り方：ピークの1%を最初に超えた地点を「発音点」とみなし、そこから **0.5秒ぶんの RMS** を取る
  （全体RMSだと、余韻の長いピアノと短い木琴で不当な差が出る。人が感じる音量にいちばん近いのが鳴り始め）
- **音階もの**：楽器ごとに全音の RMS の中央値を取り、共通の基準へそろえる
- **ドラム**：パート種別ごと（キック同士・スネア同士…）に全キットの中央値へそろえる
  → キットが本来持っている「キックとハットの比率」は壊さず、キット間の当たり外れだけ消える
- 補正は **±14dB** で頭打ち

結果、`music.js` の `gain` は「**この楽器をどのくらい前に出したいか**」だけを意味する。
ROLE ごとにほぼ同じ数値が並び、ズレていたら意図的な差、と読めるようになっている。

ブラウザのコンソールで **`studioLevels()`** と打つと、実測した補正値の一覧が出る。

## 7. ファイル構成

| ファイル | 役割 |
|---|---|
| `music.js` | 音楽そのものの定義（調・コード進行・ROLE・40枚のカードと演奏パターン） |
| `app.js` | 音響エンジンと画面（Tone.js の配線、パート、ドロップ、ビジュアライザ） |
| `samples.js` | 実録音サンプルの読み込み／ラウドネス実測／シンバル合成／楽器の生成 |
| `fetch-samples.js` | 音源のダウンロード（`音源をダウンロード.bat` から呼ばれる） |
| `cards.js` | RFID の UID とカードIDの対応表（リーダー到着後に記入） |
| `server.js` | Python が無い環境用の簡易サーバ（ポート 8770） |

カードを増やす／パターンを直すときは **`music.js` だけ**を触ればよい。`app.js` は音の出し方しか知らない。

---

## 8. RFIDリーダーが届いたら

1. メモ帳を開いてタグをかざし、打ち込まれる UID を控える
2. `cards.js` の `CARD_MAP` に `'UID': 'カードID'` の形で書く（40枚ぶんのIDはそのファイル内にコメントで全部ある）
3. そのまま `はじめる.bat` で開けば、かざした瞬間に音が入る（アプリ側の変更は不要）

## 10. 確認済み／未確認

**確認済み**（`node` 上で検証。検証スクリプトはこのフォルダには含めていない）

- 40枚すべてが 16小節まわして発音し、例外が出ないこと（実録音経路・合成音フォールバック経路の両方）
- 全カード × 4進行 × 8小節の総当たりで、音名の解決に破綻がないこと
- **サンプラーの要求音域と、実際に落ちている音源の音域の突き合わせ**
  → 移調が6半音を超えていた4か所（エレキギター・フルート・ホルン・バスーン）はパターン／オクターブを直して解消済み
- クラッシュ・ライド・オープンハット・タム2/3 がすべて実際に発火すること
- キーの重複が無いこと、40枚すべてが `CARD_ORDER` に載っていること

**未確認**

- **実際に耳で聴いた印象**。特に以下は聴かないと詰められない：
  - 合成音5枚（シンセ系）の音量。実録音側は実測でそろうが、シンセには測る対象が無いので手で置いた値のまま
  - 合成シンバル3種（クラッシュ／ライド／オープンハット）の音色と音量
  - 40枚それぞれのパターンが「音楽的に良いか」
- フレンチホルンは音源の C4 と D5 の間が14半音あいている。低い側だけ使うようにしてあるが、進行によっては補間が薄い音が出る可能性がある
