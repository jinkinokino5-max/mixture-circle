# ミクスチャー・サークル v3

**「カードを出した瞬間を気持ちよくする」ことだけを目的に作り直したアプリ。**

`output/phase0-app` / `output/studio-app` / `output/studio-app-v2` とは別の第4のアプリ。
既存3つには手を入れていない（比較用に温存）。

- **24枚** ＝ **重ねる札20枚**（4役割 × 5ジャンル）＋ **世界を塗り替える札4枚**（スタイルカード）
- **22楽器**（実録音18種＋合成音4種）。カード1枚が2〜3楽器のかたまり
- 同時に鳴らせる枚数は**開始画面で 3/4/6/8/10 から選べる**（スタイルカードはこの枚数に含まれない）

> **スタイルカード4枚** ＝ ビートルズ／藤井風／マイルス・デイヴィス＆ビル・エヴァンス／久石譲。
> 出すと、**いま鳴っている音がそのまま別の音楽に翻訳される**。
> 詳しくは「7. スタイルカード」と「8. スタイルカードの設計根拠」。

## 1. なぜ v2 は地味だったのか（作り直しの理由）

v2 を実測して分かった原因と、v3 での対処。

| v2 の問題 | v3 の対処 |
|---|---|
| **パートが増えるほど各パートを 1/√n に下げていた**（＝音を足すと音楽が小さくなる。報酬と真逆） | やめた。グルーコンプ＋リミッター＋枚数連動ゲインで、**足すほど大きく密度が上がる** |
| 投入してもループが1本増えるだけで、何も起きた気がしない | **合図→衝撃→開放**を作った（下記2章） |
| 残響センド 0.05〜0.20 で極端に乾いていた | センドを 0.05〜0.34 に上げ、**付点8分ディレイ**を追加 |
| 音が動かない（静止したループ） | **サイドチェイン・ポンピング**（キックのたび全体が43%沈んで戻る） |
| モノラルで真ん中に団子 | 役割とジャンルで**左右に配置**して広げる |
| 単音のペンタトニックで旋律が地味 | **和音ごとの「音の梯子」**を辿る方式に変更。同じ旋律の形が和音ごとに違う響きになる |
| 三和音で和音が薄い | **9th / 6th を足した5声** |
| カード＝1楽器で薄い | **カード＝2〜3楽器のアンサンブル**（サックス＋トランペット等） |
| 低音が軽い | **サブベース層**を追加（実測で35-90Hzが +3.7dB） |
| ピアノが小さい | ポップのピアノを **-11dB → -3dB** に。コード役全体も -8 → -5dB |
| 高域がこもる（実測 4kHz以上が -69dB） | マスターに**ハイシェルフ +5dB @5.2kHz**（実測 8-16kHzが +4.4dB） |

## 2. 「音を足した瞬間」に何が起きるか

キーを押してから音が入るまでの約1〜2秒に、3つのことが起きる。

1. **合図（押した瞬間）** — 「ポーン」という鐘のような音が1つ鳴り、受け付けたことを伝える。あとは無音で待つ
2. **衝撃（着弾）** — 小節頭ちょうどに **クラッシュ**（高域ノイズ）＋ **低音の一撃**。
   同時に全体が一瞬26%凹んで戻る＝「穴を開けた」ように聞こえる。画面も同時に光る
3. **登場** — 新しいパートは少し大きめ（+1.55倍）に鳴り、2小節かけて定位置の音量に落ち着く

既定の投入タイミングは「次の小節頭」。合図が鳴ってから着弾までの**間（ま）**が溜めになる。

> **「きゅいーん」は2か所にあったが、どちらも廃止した。**
> ① 投入前のライザー（220→1500Hz の上昇スイープ）
> ② パート登場時のフィルタ（460Hz→20kHz を1小節かけて開く）
> ②は「開放」の演出のつもりだったが、これ自体がフィルタスイープ＝「きゅいーん」だった。
> いまは音色を変化させる処理は一切無く、**周波数が動く箇所は残っていない**。

## 3. 使い方

1. **`音源をダウンロード.bat`** をダブルクリック（**最初の1回だけ**・約39MB・要ネット接続・要 Node.js）
2. **`はじめる.bat`** をダブルクリック → ブラウザが開く
3. 「18種類・236個の本格音源を読み込みました」と出たら準備完了
4. テンポ・制限時間・**同時枚数**・投入タイミングを選んで「はじめる」

> **できればスピーカーかヘッドホンで。** 低音とステレオが体験の半分です。

### 音源の読み込みが終わらないとき

**原因が分かっているので、対処済み。** 記録として残す。

`はじめる.bat` は以前 **Python の `http.server` を優先**していた。
このサーバーは**接続の待ち行列が5本しかない**（`socketserver` の `request_queue_size = 5`）。
一方アプリは音源236個を**一斉に**取りに行っていたので、大半が待ち行列からあふれ、
ブラウザが長いタイムアウトに入って「読み込み中のまま進まない」状態になっていた。

実測（同じ Python サーバー相手）：

| 同時に投げる数 | 取れた数 |
|---|---|
| 236（旧実装） | **50 / 236** |
| 16 | 73 / 236 |
| 6 | **236 / 236** |

対処は2つ。

1. `samples.js` … **同時6個ずつ**読み、失敗したものは最大2回まで再挑戦する
   （→ Python サーバー相手でも **236/236・0.9秒**・再挑戦0回で完了することを確認）
2. `はじめる.bat` … **Node（同梱の `server.js`）を優先**する。こちらに待ち行列の制限は無い
   （Python は Node が無いときの予備に降格）

> すでに Python のサーバーが起動したまま残っていると、`はじめる.bat` を実行しても
> **ポート8768が使用中で新しいサーバーが立ち上がらず、古いほうに繋がる**。
> 直らないときは、最小化されている「ミクスチャー・サークル v3 サーバー」の窓を
> **いったん全部閉じてから**もう一度 `はじめる.bat` を実行すること。

## 4. キー配置

**行＝ROLE（役割）／列＝GENRE（ジャンル）**。キーボードの並びがそのままグリッド。

| | ロック | ジャズ | クラシック | エレクトロ | ポップ |
|---|:-:|:-:|:-:|:-:|:-:|
| **MELODY** | `1` | `2` | `3` | `4` | `5` |
| **BASS**   | `Q` | `W` | `E` | `R` | `T` |
| **RHYTHM** | `A` | `S` | `D` | `F` | `G` |
| **CHORD**  | `Z` | `X` | `C` | `V` | `B` |

スタイルカード4枚は数字の右どなり：

| `6` | `7` | `8` | `9` |
|:-:|:-:|:-:|:-:|
| ビートルズ | 藤井風 | マイルス／エヴァンス | 久石譲 |

`Backspace` 最後の音を消す／`Esc` 終了／マスをクリックでも投入できる。

> **ファンク／ヒップホップ／ワールドの12枚は休止中。** 24枚に絞るため
> `music.js` の `GENRE_ORDER` から外しただけで、譜面は `CARDS` に残してある
> （`GENRE_ORDER` に名前を戻せば復活する。消していない）。

### カードリーダー（Mifare USB HIDリーダー）を使う場合

リーダーはキーボードとして動作し、カードをかざすとUIDを数字で打ち込んでEnterを送る。
1. `はじめる.bat` を実行してサーバーを起動した状態で `http://localhost:8768/register.html` を開く
2. マスをクリック → カードをかざす → 自動で登録され次のマスへ進む（24枚繰り返す。
   下段の4マスがスタイルカード）
3. 生成された内容をコピーして `cards.js` の `CARD_MAP` に貼り替える
4. 以降は `index.html` を開いた状態でカードをかざせば、そのままゲーム内に投入される（キー操作と併用可）

リーダー付属の設定カード（`Mifare Reader Configuration Card`）で出力フォーマットを変更した場合は、
既定の「29: QWERTYキーボード」のままにしておくこと（32: USB送出モードにすると読み取りにソフトが別途必要になる）。

## 6. 破綻しない仕組み

何を重ねても不快にならないための土台。

1. **コード進行の共有** — `Cm9 → A♭maj9 → E♭6/9 → B♭sus9`。度数では **vi–IV–I–V**、世界中のポップスで一番使われている進行
2. **和音ごとの「音の梯子」** — メロディはその和音の上で鳴らして良い音だけを辿る。全20枚が、5つのどの世界でも常に和声に乗る
3. **役割による周波数の住み分け** — BASS＝低域／CHORD＝中域／MELODY＝中高域／RHYTHM＝全域
4. **同時枚数の上限** — 超えると一番古い音がフェードアウトして抜ける
5. **拍と小節への同期** — パターン位置は常に曲全体の絶対時刻から計算するので、いつ投入しても拍子が揃う
6. **ソフトクリッパー** — 最終段の tanh で絶対に音が振り切れない

## 7. スタイルカード（世界を塗り替える4枚）

### 何が起きるか

出すと、**次の小節頭で世界そのものが入れ替わる**。譜面は1行も書き換えていない。
変わるのは「世界の定数」だけ。

| 変わるもの | 中身 |
|---|---|
| **コード進行** | 4小節ぶんまるごと。**調も変わる** |
| **音の梯子（`lad`）** | 各和音で使ってよい音。メロディの色がここで決まる |
| **テンポ** | 開始画面で選んだ値ではなく、その世界のテンポになる |
| **跳ね（swing）** | 藤井風は16分、マイルスは8分で跳ねる |
| **楽器の読み替え** | 例：シンセリード → ビートルズならエレキギター、久石譲ならフルート |
| **オクターブ** | 読み替え先の楽器の音域に合わせて自動でずらす |
| **ドラムキットと打楽器** | キット交換＋読み替え（ジャズはクラップ→ライド、久石譲はハイハット消滅） |
| **和音の積み方** | 例：マイルスではパワーコードが4度堆積に化ける |
| **ハモリ** | ビートルズのみ、メロディの強い音に3度上を重ねる |
| **音場** | 残響／ディレイ／左右の広がり／高域と中低域のバランス |

**同じカードをもう一度出すと標準の世界に戻る。**（4枚で5つの世界）
切り替えの合図から着地までの約1小節は、ほかのカードを受け付けない
（テンポが変わる瞬間をまたいで予約すると鳴り始めがずれるため）。

### 切り替えの演出

1. **合図** — 出した瞬間に「ポーン」（1枚出したときと同じ音）
2. **溜め** — 境目に向かって高域のノイズがふくらみ、古い音が引いていく
3. **着地** — 小節頭で一撃＋画面が光り、新しい世界の音が同時に始まる

高域ノイズは**音量だけ**を動かしている（周波数は動かない）ので、
v3 で廃止した「きゅいーん」（周波数スイープ）は復活していない。

## 8. スタイルカードの設計根拠

「なんとなくそれっぽい」ではなく、調べたうえで数値を決めた。根拠と出典を残す。

### ビートルズ（D調・118BPM）

- **和声**：I / IV / V / ii / vi の次に多いのが **♭VII** と **長調のII**（＝セカンダリードミナント）。
  この2つがビートルズの和声の指紋とされる。終止は ♭VII→I の二重プラガル。
  → 進行を **D6/9 → E7（長調のII） → G6/9（IV） → C6/9（♭VII）** にした。
  ループの継ぎ目が C→D ＝ ♭VII→I になる。
- **テンポ**：主要アルバムの平均が 104〜124BPM。→ **118**。
- **ハモリ**：2声のコーラスが看板。→ メロディの強い音に**梯子2段上**（＝その和音の中の3度上）を重ねる。
- **音場**：60年代の録音は乾いていて左右も狭い。→ 残響 0.62倍・ディレイ 0.25倍・広がり 0.55倍。
- **楽器**：シンセ類をギター／オルガン／エレキベースへ。
  **弦・フルート・クラリネット・ハルモニウムは残した**（『エリナー・リグビー』の弦など、実際に使われた楽器のため）。

出典：[Guitar World「Beatles chord secrets」](https://www.guitarworld.com/lessons/beatles-chord-secrets)、
[The harmonic series in the music of the Beatles](https://immed8.wordpress.com/2014/04/20/the-harmonic-series-in-the-music-of-the-beatles/)、
[GetSongBPM（アルバム別テンポ）](https://getsongbpm.com/artist/the-beatles/l2J)

### 藤井風（E♭調・88BPM・16分の跳ね）

- **和声**：**Ⅱm→Ⅴ→Ⅰ→Ⅵ** の循環（「花」は E♭調で Fm→B♭→E♭→C）にテンションとオンコードを乗せる。
  **♭9 を持つセカンダリードミナント**が手癖。
  → **Fm9 → B♭9 → E♭maj9 → C7♭9**。最後の1小節だけ D♭（♭9）が入って景色が翳る。
- **テンポ**：「何なんw」90／「帰ろう」92／「死ぬのがいいわ」79。→ **88**。
- **ノリ**：R&B／ゴスペル寄りの後ノリ。→ 16分スウィング 0.22。
- **音**：ピアノ中心・低音は深く・ドラムは手数少なめ。
  → ギターをアコギへ、シンセをピアノ／オルガンへ、ピアノ +2dB、ドラム -2dB、中低域を -3.5dB 削って低音の輪郭を出す。

出典：[藤井風の楽曲分析（5つのコード進行パターン）](https://note.com/thecreator744/n/nc7d36932837e)、
[「花」の採譜と分析](https://note.com/at_piano/n/ned5907816134)、
[BPMデータベース](https://bpm-database.tokyo/music/i3GHNIRc)

### マイルス・デイヴィス／ビル・エヴァンス（Dドリアン・132BPM・8分の跳ね）

- **形式**："So What" は **Dドリアン16小節 → E♭ドリアン8小節 → Dドリアン8小節**。和音は動かない。
  → 4小節に凝縮して **Dm11・Dm11・E♭m11・Dm11**。3小節目だけ半音上へずれて戻る。
- **和音**：ビル・エヴァンスはルートを弾かず、3度堆積ではなく**4度堆積**で長短どちらでもない色を作る。
  "So What コード" は下から **E-A-D-G-B**（4度を3つ積んで最上段だけ3度）。
  → `vc` にその積みをそのまま入れた。パワーコードもルートレスに化ける。
- **リズム**：ウォーキングベースとライド／ブラシ。クラップは存在しないので**ライドに読み替え**。
- **音量**：全体に小さく間がある。→ エネルギー 0.85倍、ドラム -3dB。
- **楽器**：『カインド・オブ・ブルー』にギターもシンセも無い。→ 全部トランペット／サックス／ピアノ／ウッドベースへ。

出典：[Wikipedia "So What"](https://en.wikipedia.org/wiki/So_What_(Miles_Davis_composition))、
[The So What Chord（4度堆積）](https://piano.org/theory/so-what-voicings/)、
[Kind of Blue（編成・ブラシ）](https://en.wikipedia.org/wiki/Kind_of_Blue)

### 久石譲（ハ長調・76BPM）

- **和声**：sus4/sus2/11th の多用と**4度堆積**、分数コード、**借用和音**、
  サビ後半で半音下の **♭IIImaj7** に飛んで景色を変える。
  → **Cadd9 → Fmaj9 → E♭maj9（♭III） → Fm9（借用したⅣm）**。
  ループの継ぎ目 Fm→C（Ⅳm→Ⅰ）が「ジブリの切なさ」の正体。
- **メロディ**：ペンタトニック。→ 梯子を各和音のペンタトニックで組んだ。
- **音場**：「空気感」が持ち味。→ 残響 1.6倍・高域 +4.5dB・広がり 1.15倍。
- **楽器**：弦・ピアノ・ハープ・ホルン。ギター類はハープへ、シンセは弦とフルートへ。
  **ハイハットは消し**、スネアとクラップはティンパニ（タム）に読み替える。

出典：[久石譲っぽいコード進行の作り方（4度堆積・sus・借用）](https://musekinote.com/gibli_code/)、
[『あの夏へ』のコード進行解説（分数コード・♭IIImaj7・Fmaj7#11）](https://type00k.com/one-summer-day-day/)、
[千と千尋の音楽分析](https://note.com/yasuaki_1220/n/na10a93196eb9)

> ⚠️ ここに書いたのは**「その音楽の特徴として一般に解説されている事柄」**であって、
> 本人の作曲手順ではない。似せているのは和声・テンポ・楽器・ノリであって、
> 旋律の節回しそのものではない。**「〜風」であって「〜の曲」ではない。**

## 10. 音を調整したいとき

`music.js` の上から順に、独立して触れる。

- **`PROG`** … コード進行そのもの。`lad`（音の梯子）を変えると全メロディの色が変わる
- **`ROLES`** … 役割ごとの帯域・オクターブ・音量・残響/ディレイ量・定位
- **`VOICES`** … 楽器ごとの音源名とアタック／リリース
- **`CARDS`** … 20枚ぶんの譜面と**楽器のレイヤー構成**
- **`STYLES`** … スタイルカード4枚の中身（進行・テンポ・跳ね・楽器の読み替え表・音場）。
  **アーティストらしさを調整したいときはここだけ触ればいい**
- **`VOICES` の `ctr`** … 楽器の中心オクターブ。読み替えたとき何オクターブずらすかの基準

`engine.js` 側で触るなら：

- **`schedulePump`** … ポンピングの深さ（今は 0.28＋0.04×枚数、上限0.50）
- **`playCue` / `playImpact`** … 合図音と着弾の一撃の強さ
- **`Bus.air` / `Bus.mud`** … 全体の音色（高域の空気感／中低域のもたつき）

## 12. 動作確認済みのこと

Chrome で起動し、**最終出力の波形とスペクトルを実測**して確認した。

- 音源 **18種類・236個**の読み込み（エラーなし）
- **全32枚が発音すること**（4小節ぶん再生して発音回数を計測。**無音のカードなし**）
- 全32枚 × 全レイヤー × 全和音が作る音名が、各音源の実在音域に収まること
  （この検査でロックのギターが D6〜A#6 まで上がっていたのを発見し、オクターブを下げて修正）
- **足すほど大きくなること**：土台のみ RMS 0.017 → 6枚 RMS 0.24（**約14倍**）
- **合図音が「ポーン」であること**：主要周波数が **785Hz で完全に固定**（測定中の変化 0Hz）、
  約600msでなめらかに減衰。上昇スイープは無い
- **フィルタが開く演出が消えていること**：`Part` に `entry` フィルタが存在しないことを実行時に確認。
  着弾直後と8秒後で音色の明るさが増えない（むしろ自然に減衰する方向）
- **合図→間→衝撃**の流れが波形に現れること
- **ポンピング**が実測 **43%** の沈み込みで動作すること
- **ハイシェルフ**が 8-16kHz を +4.4dB 持ち上げ、低域は +0.2dB で不変であること
- **サブベース**が 35-90Hz に +3.7dB 寄与すること
- 8枚同時でも**最大ピーク 0.86 でクリップしない**こと（ソフトクリッパーの効果）
- 同時枚数の上限（3/4/6/8/10）が切り替わり、超過分の最古が押し出されること
- 終了時に録音（.webm）が生成され、再生・保存できること

**未確認：** 音楽的な良し悪しそのもの。**これは耳で聴いて判断するしかない。**
上の数値は「設計どおり動いている」ことの確認であって、「良い音である」ことの証明ではない。

> 補足：検証中、再生しながら BPM を変更した直後に投入したカードが鳴らない現象が出たが、
> BPM を開始前に設定した場合は全32枚が正常に発音した。アプリは開始前にしかテンポを変えられないので
> 通常の使用では起こらないが、将来「演奏中にテンポを変える」機能を足すなら要調査。
> → **スタイルカードで演奏中にテンポが変わるようになったので、下記のとおり対処した。**

### 12-b. スタイルカードを足したあとの確認（24枚版）

**この回の検証はブラウザではなく、Tone.js と DOM を差し替えた Node 上で
`music.js` / `samples.js` / `engine.js` / `app.js` の実物を動かして行った**
（作業環境からブラウザを操作できなかったため）。
「どの楽器のどの音を、いつ鳴らそうとしたか」は全部記録して数えている。

- **5つの世界（標準＋4枚）すべてで、20枚が1枚も無音にならない**
  （各カードを4小節ぶん走らせて発音回数を計測）
- **5つの世界 × 20枚 × 全レイヤー × 全和音**が作る音名を全部展開し、
  音源を **4半音を超えて引き伸ばす音がゼロ**であること
  （最大の引き伸ばしは4半音。標準の世界の従来値は最大3半音で、悪化していない）
- スタイルカードを出すと、**進行・テンポ・跳ね・楽器・ドラムキットが実際に入れ替わる**こと
  （例：ロックのメロディが標準＝エレキギター → 久石譲＝ハープ に変わる）
- **鳴っていたカードが1枚も落ちずに作り直され**、新しい世界で走り出すこと
- **同じ札をもう一度出すと標準に戻り、テンポが開始画面で選んだ値に戻る**こと
- 切り替え中（合図から着地までの約1小節）は**ほかのカードの投入が弾かれる**こと
- 画面の組み立て（20マス＋スタイル4枚）が例外なく通ること
- カードIDが **ちょうど24種**で、キー `1`〜`5` `Q`〜`T` `A`〜`G` `Z`〜`B` `6`〜`9` に
  重複なく割り当たっていること

**BPM変更の不具合への対処：** 上の補足にあった現象は、テンポを
`Tone.Transport.bpm.value = x` と直接代入して起きていた可能性が高い。
今回は **`bpm.setValueAtTime(新テンポ, 小節頭の時刻)`** で「その瞬間に切り替える」形にし、
さらに切り替えをまたぐ投入をガードで弾いている。

**この回で確認できていないこと（実機で聴く必要がある）：**

- 実際の音（4つの世界がそれぞれ「らしく」聞こえるか）。**これが本丸で、耳でしか判断できない**
- スウィング（`Tone.Transport.swing`）を掛けたときの、既存のジャズ譜面との相性。
  ジャズのカードは元々「16分の位置に置いて跳ねを模した」譜面なので、
  マイルスの世界では**二重に跳ねて不自然になる可能性がある**
- 切り替えの瞬間の音の途切れ・クリックノイズの有無
- 実際の波形／スペクトル（前回のような RMS・周波数の実測はしていない）
