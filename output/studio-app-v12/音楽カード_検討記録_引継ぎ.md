# 音楽カード拡張プロジェクト 検討記録（引継ぎ用）

作成日: 2026-09-02
対象: `stone-app-v5`（石！！石？？石！？）の音楽カード（`music.js` の WORLDS/PHRASES）を増やすための試聴・選定プロセス

---

## 1. 目的

- 既存アプリ本体（app.js / engine.js / cards.js / music.js / samples.js 等）は**変更しない**方針を維持したまま、
  「音のスケッチ」候補をブラウザで試聴してお気に入り登録できる独立ツール（`card-audition*.html/js`）を複数ラウンド作成。
- 最終的にユーザーが実際に気に入った組み合わせだけを、本体の `music.js` に本物の音楽カード（WORLD/PHRASE）として追加する予定（**この実装フェーズはまだ未着手**）。

## 2. わかったこと（各ラウンドの結論）

### ラウンド1（`card-audition.html`）— コード進行10種 × 雰囲気10種
- 結論: **コード進行はほぼ判断に影響しない**。同じ「雰囲気」（楽器構成）なら進行を変えても好き嫌いが変わらなかった。
- 好まれた雰囲気: m3(シティ夕方) / m6(ジャズ夜想) / m7(ローファイ午後) が全10進行で★。m1(夜のピアノ)は3/10、m5(ハープの瞑想)は2/10のみ。

### ラウンド2（`card-audition2.html`）— 新コード×新雰囲気10種
- ユーザーコメント: 「ビッグバンドのホーン（トランペット comp + Kit3 swingドラム）が良かった」→ 以降のラウンドで重点的に深掘り。

### ラウンド3（`card-audition3.html`）— 進行固定・音色10種×リズム10種
- **進行を固定してリズム感を変える方式に転換**（ユーザー指摘：「見たいのはコード進行より楽器の組み合わせとリズム感」）。
- 結論:
  - **t8 ビッグバンドのホーン（trumpet comp + bass-electric）→ 全10リズムで★**（最強の当たり）
  - **t2 シティ夕方（guitar-electric comp + bass-electric + xylophone）→ 9/10で★**（レゲエのみ外れ）
  - t1 夜のピアノ → 3/10（r7ファンク／r8テクノ／r10ビッグバンドスウィングのみ）
  - t4 ジャズ夜想／t5 ローファイ午後 → **0/10**（ラウンド1と矛盾。ユーザー確認済み：「もう好みじゃない。ラウンド3が正しい」）
- → **採用済み（本体に入れてよい）としてユーザーが指定した実データ**: 上記 t1/t2/t8 の全★組み合わせ（`card-audition3-favorites.json` 参照、計23件）。

### ラウンド4（`card-audition4.html`）— 楽器パレット開拓（リード20種×ベース5種、進行・リズム完全固定）
- 結論: **ベース楽器の違いはほぼ判断に影響しない**。リード/コード楽器の選択が支配的。
- 全ベース(5/5)で★だった楽器: harp, guitar-electric, flute（xylophoneは4/5）
- 一度も★が付かなかった楽器: organ, violin, saxophone, trombone, synth-pad, synth-organ, synth-bell
- → 採用データ: `card-audition4-favorites.json`（41件）

## 3. 全ラウンドを通した確定傾向（重要）

1. **コード進行はほぼ無視してよい**（vi–IV–I–V／G の定番進行で固定運用中）。
2. **判断を左右するのはほぼ「楽器の組み合わせ」と「リズム/グルーヴ」のみ**。ベース楽器単体の違いは弱い信号。
3. 強い当たり楽器（単独〜複層）:
   - トランペット中心のホーン（単体〜3管ハーモニー）
   - ギター（エレキ comp／アコギ arp）中心の編成
   - harp, xylophone, guitar-electric, flute（ラウンド4基準）
4. 弱い/外れやすい楽器: organ, violin単体, saxophone単体, trombone単体, 各種シンセ(pad/organ/bell)
5. ラウンド1とラウンド3の間で「ジャズ夜想／ローファイ午後」への評価が逆転 → **直近のラウンド3の結果を正とする**（ユーザー確認済み）。
6. リズム面では、グルーヴ次第で好みが割れることは少なく、**楽器編成そのものの当たり外れの方が支配的**（ラウンド5で顕著：良い編成はグルーヴをほぼ問わず好評、悪い編成はどのグルーヴでも★ゼロ）。
