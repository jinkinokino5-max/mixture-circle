# stone-app-v15 PDCAログ（第9回）— 既存カードの見直し 第3弾

恒久PDCAサイクル第9回。v14で見つけた「trumpet+saxophoneの組み合わせ」
残り7件（kaze.color/modal.core/modal.push/lofi.push/funk.push/
reggae.push/swing.core）を1件ずつ確認した。

## Plan（計画）
各世界のコード内コメントを読み、その世界の「編成の根拠」節に
horn/管セクションについての明示的な記述があるかどうかで判断する
（無ければcitypopと同じ理由で修正、あれば genre的に正当な選択として残す）。

## Do（実行・判断結果）
- **kaze.color**：world冒頭コメントに「ドラムやベース、ギターや
  サンプリング音源でのプログラミング、ストリングス、ホーンセクション
  などを合わせて組み立てていく」と明記——藤井風の実際の編曲手法として
  ホーンセクションが含まれる。**据え置き**。
- **modal.core / modal.push**：world冒頭コメントに「カインド・オブ・
  ブルーの六重奏は…トランペット／アルトサックス／テナーサックス…」
  と実在のセクステットが明記されている。**据え置き**（v12で確認済みの
  判断を再確認）。
- **funk.push**：world冒頭コメントに「ホーンセクション（サックス＋
  トランペット＋トロンボーン）…が土台」と明記。ジェームス・ブラウンの
  ホーンセクションそのもの。**据え置き**。
- **reggae.push**：カード内コメント「スカのホーンライン」。スカ／
  レゲエの管楽器セクションは音楽ジャンルとして広く確立された定番。
  **据え置き**。
- **swing.core**：world冒頭コメントに「この世界だけ管楽器が全部いる
  （トランペット・トロンボーン・サックス・クラリネット）」と明記。
  ビッグバンドの管セクションそのもの。**据え置き**（v12で確認済みの
  判断を再確認）。
- **lofi.push**：カード内コメントは「管が前に出る場面。それでも
  こもっている」のみで、他5件のような具体的なジャンル的根拠が無い。
  ロー・ファイ・ヒップホップに管セクションを前面に出す強い伝統は
  無く、citypopと同様「なんとなく置いた」組み合わせと判断。
  **accentをtrumpet→guitar-electricへ修正**（lp値はそのまま維持し、
  こもった質感は変えていない）。

## Check（確認）
- `node --check music.js` → 構文OK
- 構造整合性チェック（Node、単一eval）：missingVoice 0・missingGroove 0
- `WORLDS.lofi.voices.push.melody`が`['saxophone', 'guitar-electric']`に
  変わったことを確認
- 全コアJSファイルで`node --check`構文OK
- 実際に鳴らしての確認は今回省略（ユーザー指示により不要）

## Act（次への反映）
- v14〜v15で見つけた「trumpet+saxophone」8件のうち、citypop（3件）と
  lofi（1件）の計4件を修正、genre的根拠のある6件（modal×2・swing・
  funk・reggae・kaze）は据え置いた。この一連の見直しはここで一区切り。
- 同様の「組み合わせ単位でgrepして、根拠の有無で判断する」手法は、
  他の試聴5周目の「弱い」判定（例：a1トランペット単体ユニゾン、
  静かなバラード＝ドラムなしピアノ+バイオリンpad、ジャングリーポップ＝
  2本のarpギター）にも応用できる。次回以降の候補にする。
- 次のサイクルの候補：
  a) card-gain.jsを定点観測し、新しいユーザー操作データがあれば焼き込みを検討
  b) phraseOverridesが無い世界（motown以外の18世界）に、新規作曲した
     固有メロディを追加する
  c) 「静かなバラード」「ジャングリーポップ」など、試聴5周目で確定した
     他の弱い組み合わせが既存世界に紛れ込んでいないか同様にgrepする
- 次はどれかを実施し、`stone-app-v16`として切り出す。
