# STUDIO PULSE — ROLE × INSTRUMENT 版（studio-app-v4）

ジャンル（ジャズ／ロック／クラシック／エレクトロ）を**撤廃**した新しいスタジオアプリ。
カードは **ROLE（曲の中で何をするか）× INSTRUMENT（何の音でするか）** の2軸だけでできている。

参照：`reference/音楽カードのサウンド設計1.txt` の ROLE 4分類（MELODY／BASS／RHYTHM／CHORD）をそのまま骨格に採用。

---

## 1. 使い方

1. **`音源をダウンロード.bat`** を最初に1度だけ実行（インターネット接続が必要／約20MB）
2. **`はじめる.bat`** をダブルクリック → ブラウザが開く
3. 「はじめる」を押して、キーボードでカードを重ねる

※ `index.html` を直接ダブルクリックしても動くが、ブラウザの制限で音源が読めず全パート合成音になる。必ず `はじめる.bat` から開く。

---

## 2. 操作

| 操作 | 内容 |
|---|---|
| `1`〜`8` | MELODY（曲の顔）8枚 |
| `Q W E R T Y U I` | CHORD（曲の空間）8枚 |
| `A S D F G H J K` | BASS（曲の足元）8枚 |
| `Z X C V B N M ,` | RHYTHM（曲の動き）8枚 |
| **スペース** | **ビルドアップ＆ドロップ**（2小節かけて持ち上げ、次の小節頭で落とす） |
| `↑` `↓` | ENERGY（静／走／熱） |
| `P` | コード進行を切り替え（夜／陽／呪／都） |
| `Backspace` | 最後に入れた1枚を戻す |
| `Esc` | 終了（録音を書き出す） |
| クリック | カード投入。**同じカードをもう一度押すと止まる** |

同時に鳴らせる枚数：**MELODY 2 / CHORD 2 / BASS 1 / RHYTHM 2**。
上限を超えると、その ROLE のいちばん古い音と自動で交代する（全体が消えるのではなく役割単位で入れ替わる）。

---

## 3. 音楽の骨組み（v1 からの変更点）

ジャンルという「外側のラベル」を捨てた代わりに、全パートが共有する土台をエンジン側が握っている。
だから **どのカードとどのカードを重ねても必ず噛み合う。**

| 仕組み | 内容 |
|---|---|
| 調 | Cマイナー（＝E♭メジャー）に固定 |
| コード進行 | 4小節でひと回り。4種類（夜／陽／呪／都）を演奏中に切り替え可 |
| ボイスリーディング | 構成音を -6〜+5半音に畳み込み、コードが変わっても音域が跳ねない |
| サイドチェイン | キックが鳴るたび上ものが一瞬へこむ＝ビートが前に出る |
| キック権 | 最初に入ったリズムカードだけがキックを出す。重ねても土台は濁らない |
| 自動フィル | 8小節ごとの4拍目にスネアの畳みかけ |
| ビルド＆ドロップ | ハイパス上昇＋ノイズライザー＋スネアロール → 一瞬の無音 → 落とす |
| ENERGY | 静／走／熱で、細かい音の量と強さが変わる |
| スウィング | 0〜55%（16分）。同じカードでもノリが変わる |
| 基礎ビート | リズムカードが0枚のときだけ鳴り、入ると静かに引っ込む |

## 4. カード一覧（32枚）

**MELODY（曲の「顔」）**
ピアノ／エレキギター／サックス／ヴァイオリン／フルート／トランペット／チェロ（旋律）／シンセリード

**CHORD（曲の「空間」）**
ピアノ／アコギ／カッティング／オルガン／ハープ／ストリングス／ブラス／シンセパッド

**BASS（曲の「足元」）**
エレキベース／ウッドベース／チェロ／オルガンベース／ピアノ（低音）／シンセベース／ファズベース／サブベース

**RHYTHM（曲の「動き」）**
生ドラム／ブレイクビーツ／四つ打ち／ドラムマシン／80sマシン／シェイカー／パーカッション／木琴

シンセ系4枚（シンセリード／シンセパッド／シンセベース／ファズベース）以外はすべて**実録音**。
画面の各カード右上に「実録音／合成音」が出る。

## 5. ファイル構成

| ファイル | 役割 |
|---|---|
| `music.js` | 音楽そのものの定義（調・コード進行・ROLE・32枚のカードと演奏パターン） |
| `app.js` | 音響エンジンと画面（Tone.js の配線、パート、ドロップ、ビジュアライザ） |
| `samples.js` | 実録音サンプルの読み込みと楽器の生成 |
| `fetch-samples.js` | 音源のダウンロード（`音源をダウンロード.bat` から呼ばれる） |
| `cards.js` | RFID の UID とカードIDの対応表（リーダー到着後に記入） |
| `server.js` | Python が無い環境用の簡易サーバ |

カードを増やす／パターンを直すときは **`music.js` だけ**を触ればよい。`app.js` は音の出し方しか知らない。

---

## 6. RFIDリーダーが届いたら

1. メモ帳を開いてタグをかざし、打ち込まれる UID を控える
2. `cards.js` の `CARD_MAP` に `'UID': 'カードID'` の形で書く（IDの一覧はそのファイル内にコメントで全部ある）
3. そのまま `はじめる.bat` で開けば、かざした瞬間に音が入る（アプリ側の変更は不要）

## 8. 確認済み／未確認

- 確認済み：32枚すべての音名解決（4進行 × 全コードで総当たり、破綻ゼロ）、7パート同時演奏、役割ごとの枚数上限と交代、キック権の委譲、ビルド＆ドロップ後の復帰、録音の書き出し、コンソールエラーなし
- 未確認：**音楽的な良し悪し（実際に聴いた印象）**。パターンの粒度・音量バランスは耳で詰める余地がある
