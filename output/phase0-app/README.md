# Phase 0 アプリ — ミクスチャー・サークル（キーボード版）

`draft/実装計画.md` の Phase 0（費用0円・RFIDリーダー到着前に「面白い」を確かめる）の実装。

## 使い方

**`はじめる.bat` をダブルクリック** → ブラウザが自動で開きます。
インストール・ビルド・ネット接続はすべて不要（Tone.js は `vendor/` に同梱済み）。
遊び終わったら、最小化された「ミクスチャー・サークル サーバー」の窓を閉じてください。

`index.html` を直接ダブルクリックしても遊べますが、`file://` ではブラウザの制限で
**残響（リバーブ）だけが無効**になります（音は問題なく鳴ります）。
音質を確かめたいときは `はじめる.bat` のほうを使ってください。

1. テンポ（BPM）・制限時間・同期のしかたを選ぶ
2. 「はじめる」を押す → 基礎ビートが流れ出す
3. キーを押すと、**次の拍頭から**その音が加わる
4. 時間が来ると余韻を残して終わり、**演奏の録音**が再生できる（保存も可）

## キー配置（＝カードのグリッド）

行がジャンル、列が楽器。キーボードの物理的な並びがそのままグリッドになっている。

|            | ピアノ | ギター | ベース | ドラム | ストリングス | シンセ |
|------------|:---:|:---:|:---:|:---:|:---:|:---:|
| ジャズ       | `1` | `2` | `3` | `4` | `5` | `6` |
| ロック       | `Q` | `W` | `E` | `R` | `T` | `Y` |
| クラシック    | `A` | `S` | `D` | `F` | `G` | `H` |
| エレクトロ    | `Z` | `X` | `C` | `V` | `B` | `N` |

- `Backspace` … 最後に入れた音を消す
- `Esc` … 終了する
- 画面のマスをクリックしても投入できる（スマホ・タブレットでも遊べる）

## 実装している設計上の約束（実装計画 6章）

| 内容 | 実装 |
|---|---|
| キーの固定 | 全パートを **Cマイナー・ペンタトニック**（C, E♭, F, G, B♭）に統一。何を重ねても破綻しない |
| 周波数の住み分け | ベース=低域 / ギター・ピアノ=中域 / ストリングス・シンセ=高域。楽器ごとにフィルタで帯域を分離 |
| 同時発音数の上限 | 最大6パート。7つ目を入れると**一番古いものがフェードアウト**して抜ける |
| 音量の自動調整 | パート数が増えるほど1パートあたりを下げ、全体の音量を一定に保つ（最後にリミッター） |
| ジャンル＝リズムの性格 | ジャズ=裏拍・シンコペーション / ロック=8分・強拍 / クラシック=伸びる音 / エレクトロ=16分・機械的 |
| 拍頭への同期 | 押した瞬間ではなく、**次の拍頭（または小節頭）のティック位置**に予約して発音を開始 |
| 二重読みガード | 同じカードは500ms以内の連続入力を無視。すでに鳴っているカードは無視して画面で知らせる |

## 印刷用カード

`cards-print.html` を開いて「印刷する」→ A4×3ページに24枚（63×88mm、TCG標準サイズ）。
破線で切り、厚紙に貼る。中央の円が **NFCシールを貼る位置**（全カードで同じ位置＝読み取り率が安定する）。

## Phase 1 への移行（リーダーが届いたら）

キーボードをUIDに差し替える作業は、**`cards.js` を書くだけ**で済むようにしてある。

1. メモ帳を開いてNFCシールをかざし、打ち込まれるUIDを24枚ぶん控える
2. `cards.js` の `CARD_MAP` に `'UID': 'ジャンル-楽器'` の形で記入する
3. それだけ。HIDリーダーの入力（数字の連打＋Enter）を `app.js` が拾い、`insertCard()` を呼ぶ

外部から呼べる入口として `window.insertCard('jazz-piano')` を用意してある。

## 音を変えたいとき

`app.js` の上の方だけ見ればよい。

- `INSTRUMENTS` … 楽器ごとの音色・オクターブ・帯域・音量
- `GENRES` … ジャンルごとのリズムパターン（1小節＝16ステップ）とドラムパターン
- `PENTA` … 使う音階
- `MAX_PARTS` … 同時発音数の上限
