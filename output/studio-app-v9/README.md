# ミクスチャー・サークル v9

**ジャンルを撤廃したバージョン。** カードは「何をする札か」だけを持ち、
**楽器は世界（スタイルカード）の側が決める。**

`output/studio-app-v3` を複製して作った。v3 には手を入れていない（比較用に温存）。

- **24枚** ＝ 重ねる札 **20枚**（4役割 × 5性格）＋ 世界を決める札 **4枚**
- 5つの世界（標準・ビートルズ・藤井風・マイルス＆エヴァンス・久石譲）が
  それぞれ **20枠ぶんの楽器編成を丸ごと持っている**
- 同時に鳴らせる枚数は開始画面で 3/4/6/8/10 から選べる（スタイル札は枚数に含まれない）

---

## 1. v3 から何を変えたのか

### 問題：ジャンルと世界が二重になっていた

v3 の列は **ロック／ジャズ／クラシック／エレクトロ／ポップ** というジャンルだった。
そこにスタイルカード（世界）を足した結果、

> **「マイルスの世界の、ロックのカード」**

という意味の通らない札ができてしまった。
しかも楽器は「エレキギター → ハープ」のような**機械的な読み替え**で決めていたので、
その音楽に実在しない編成（ジャズの世界にシンセパッド等）が平気で出ていた。

### v9 の答え：札は「はたらき」だけ持つ。楽器は世界が持つ

| | v3 | v9 |
|---|---|---|
| 列 | ジャンル（ロック／ジャズ…） | **性格**（軸／歌／押し／刻み／彩り） |
| 札が持つもの | 譜面 **＋ 楽器** | **譜面だけ** |
| 楽器を決めるのは | 札（＋機械的な読み替え） | **世界（20枠を手で決めた編成表）** |
| その音楽に無い楽器 | 混ざりうる | **最初から存在しない** |

**実測：5つの世界すべてで同じ楽器のままの札は 0 / 20 枚。**
どの札も、世界が変われば必ず別の楽器で鳴る。

## 2. カードの列＝性格（CHARACTER）

ジャンルではないので、どの世界にも5つとも存在する。

| | 意味 | 譜面の中身 |
|---|---|---|
| **軸 CORE** | 背骨 | 素直な8分。口ずさめる形 |
| **歌 SING** | 伸びる | 長い音。4小節でひとつの物語 |
| **押し PUSH** | 前へ | 8分で押し出す。いちばん力強い |
| **刻み DRIVE** | 走る | 16分の反復。機械的な推進力 |
| **彩り COLOR** | 飾る | 裏拍と合いの手。休符が主役 |

各マスに出るのは **はたらき**（世界が変わっても変わらない）と、
その下に小さく **いまの世界での楽器**（世界が変わると入れ替わる）。

## 4. 編成の根拠（調べたこと）

### ビートルズ

『ラバー・ソウル』で**ハルモニウム**を導入し、『リボルバー』では
「エリナー・リグビー」の**弦楽八重奏**とホーンの編曲を持ち込んだ。
「Think for Yourself」では通常のベースに**ファズベース**を重ねている。
ポール・マッカートニーのベースは12度を駆け上がるなど旋律的。

→ 「歌」の列を弦とハルモニウムに、「押し」のベースにファズベース層を、
「彩り」をホーンセクションに割り当てた。

出典：[Guitar World「Rubber Soul の楽器」](https://www.guitarworld.com/magazine/guide-songs-and-instruments-featured-beatles-rubber-soul-album)、
[Wikipedia: Rubber Soul](https://en.wikipedia.org/wiki/Rubber_Soul)、
[Wikipedia: Revolver](https://en.wikipedia.org/wiki/Revolver_(Beatles_album))

### 藤井風

全曲を **Yaffle** が編曲・プロデュースしており、
「ドラムやベース、ギターやサンプリング音源でのプログラミング、ストリングス、
ホーンセクションなどを合わせて組み立てていく」手法。
つまり**生楽器と打ち込みが同居する**。中心はあくまでピアノ。

→ v3 では全部ピアノに寄せていたが、v9 では
「刻み」だけを打ち込み（シンセベース＋LINN）に、「歌」をストリングスに、
「彩り」をホーンとゴスペルのオルガンに分けた。

出典：[Yaffle の制作手法](https://note.com/ancora/n/n844dd6bb6d4c)、
[藤井風 - Wikipedia](https://ja.wikipedia.org/wiki/%E8%97%A4%E4%BA%95%E9%A2%A8)

### マイルス・デイヴィス／ビル・エヴァンス

『カインド・オブ・ブルー』の六重奏は
**トランペット／アルトサックス／テナーサックス／ピアノ／ウッドベース／ドラム**。
**ギターもシンセも1本も入っていない。**

→ この世界には**ギターとシンセを1つも置かなかった**（テストで検査している）。
ベースは全枠ウッドベース。和音はすべてピアノ。

出典：[Kind of Blue（編成）](https://en.wikipedia.org/wiki/Kind_of_Blue)、
[アルバム解説](https://bestofjazz.org/miles-davis-kind-of-blue/)

### 久石譲

大編成ではなく**小さめのオーケストラ**を使い、楽器と音色を場面ごとに丁寧に描き分ける。
『風の谷のナウシカ』などでは**ミニマル・ミュージックの手法**
（動きを最小限にした反復）が使われている。

→ 弦・ピアノ・ハープ・木管・ホルンだけで組み、
**「刻み」の札をミニマルな反復**（シロフォン＝グロッケン役）に当てた。
金管が前に出るのは「押し」だけ。

出典：[久石譲 - Wikipedia](https://ja.wikipedia.org/wiki/%E4%B9%85%E7%9F%B3%E8%AD%B2)、
[久石譲っぽいコード進行の作り方](https://musekinote.com/gibli_code/)、
[『あの夏へ』の解説](https://type00k.com/one-summer-day-day/)

> ⚠️ ここに書いたのは**「その音楽の特徴として一般に解説されている事柄」**であって、
> 本人の制作手順ではない。似せているのは編成・和声・テンポ・ノリであって、
> 旋律そのものではない。**「〜風」であって「〜の曲」ではない。**

## 7. 使い方

1. **`音源をダウンロード.bat`**（最初の1回だけ・約39MB・要ネット接続・要 Node.js）
2. **`はじめる.bat`** → ブラウザが開く
3. 「18種類・236個の本格音源を読み込みました」と出たら準備完了

> **できればスピーカーかヘッドホンで。** 低音とステレオが体験の半分です。

読み込みが終わらないときの原因と対処は v3 の README「3. 使い方」に記録してある
（Python の `http.server` は待ち行列が5本しかない。v9 も同じ対処済み：
同時6個ずつ読み、`はじめる.bat` は Node を優先する）。

## 9. 音を調整したいとき

**`music.js` の `WORLDS` だけ触れば、その世界の音がすべて変わる。**

- `voices[性格][役割]` … その札をその世界で何で鳴らすか（★これが v9 の主役）
- `prog` / `bpm` / `swing` / `harmony` … 和声とノリ
- `sendScale` / `air` / `mud` / `panScale` … 部屋の響き
- `drumMap` … 打楽器の読み替え（`h: null` でハイハットを消す 等）

譜面を変えたいときは `PHRASES`。こちらは**全世界に影響する**。

## 10. 動作確認済みのこと

ブラウザではなく、**Tone.js と DOM を差し替えた Node 上で
`music.js` / `samples.js` / `engine.js` / `app.js` の実物を動かして**検証した
（作業環境からブラウザを操作できなかったため）。

- 音源 **18種類・236個**の読み込み
- **5つの世界すべてで、20枚が1枚も無音にならない／すべて実録音で組み上がる**
- **5つの世界すべてで同じ楽器のままの札は 0 / 20**（＝必ず編成が変わる）
- **マイルスの世界にギターとシンセが1本も無い**こと（自動検査）
- **久石譲の世界にギターとシンセが1本も無い**こと（自動検査）
- 5世界 × 20枚 × 全レイヤー × 全和音の音名を全展開し、
  音源を **4半音を超えて引き伸ばす音がゼロ**であること
  （世界ごとの最大：標準3／ビートルズ4／藤井風4／マイルス4／久石譲3 半音）
- スタイルカードで**進行・テンポ・跳ね・編成が実際に入れ替わる**こと
- **鳴っていた札が1枚も落ちずに作り直され**、新しい世界で走り出すこと
- 同じ札をもう一度で標準に戻り、テンポが開始画面の値に戻ること
- 切り替え中（約1小節）はほかの札の投入が弾かれること
- 画面の組み立て（20マス＋スタイル4枚）が例外なく通ること／カードIDがちょうど24種

> この検証で実際にバグが1つ見つかっている（`app.js` が呼ぶ `applyWorldTone` を
> `engine.js` 側で改名し忘れていた。ブラウザなら世界の切り替えで必ず落ちていた）。

**この回で確認できていないこと（実機で聴く必要がある）：**

- **実際の音。5つの世界がそれぞれ「らしく」聞こえるか。これが本丸で、耳でしか判断できない**
- 特に **マイルスの世界のスウィング**。「彩り」の譜面は元々
  「16分の位置に置いて跳ねを模した」作りなので、**二重に跳ねて不自然になる可能性がある**
- 世界の切り替えの瞬間の音の途切れ・クリックノイズの有無
- 波形／スペクトルの実測（v3 で行った RMS・周波数の測定は今回していない）
