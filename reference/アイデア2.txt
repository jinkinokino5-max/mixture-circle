【ミクスチャー・サークル：基本設計アイデア】

■ 基本思想
・「音楽版トランプ」を目指す
・カードセットは汎用的に、遊び方を複数用意する
・基本操作は極力シンプル
　→ 引く／選ぶ／出す／聴く
・勝敗あり／なし、協力／競争などは遊び方ごとに変える

■ 音楽カード
・カード＝音楽の部品
・基本表記：
　MELODY
　Piano
・役割候補：
　MELODY / FOUNDATION / RHYTHM / TEXTURE / ACCENT
・楽器候補：
　Piano / Guitar / Bass / Drums / Synth / Brass / Violin / Flute etc.
・ジャンル：
　Jazz / Rock / Classical / Electronic / Folk etc.
・「役割×楽器×ジャンル」で音の個性を作る

■ 音楽以外のカード候補

【THEME】
・夜の浜辺
・初恋
・雨の日の東京
・宇宙船の中
・世界が終わる前夜
・100年後の夏
・誰にも言えない秘密

【MOOD】
・穏やか
・不安
・幸福
・孤独
・興奮
・不穏
・懐かしい

【ACTION】
・ANSWER：誰かの音に答える
・CONTRAST：正反対の音を加える
・FOLLOW：前の音についていく
・REMOVE：何かを抜く
・CHANGE：曲の方向を変える

【TIME】
・INTRO
・BUILD
・BREAK
・CLIMAX
・END

■ 遊び方の可能性
・お題に合わせてみんなで曲を作る
・音楽しりとり
・音楽で感情を伝える
・一人だけ別のお題を持つ推理ゲーム
・「今の曲に足りないもの」を考える
・完成した曲から情景を想像する
・カードを交換して曲を作る
・一人ずつ曲の方向を変える
・個人の作品を作る
・全員で一つの作品を作る

■ 重要な設計思想
・カードの種類を増やしても、基本操作は増やさない
・「カードを出す」だけで音楽が変化する
・音楽知識を要求しない
・カードを出す／出さない自体が意思決定
・完成した音楽を「聴く・解釈する」ことも遊びにする
・同じカードセットから複数のゲームを成立させる

■ 今は決めない
・カード総数
・役割の種類
・ジャンル数
・特殊カードの詳細
・勝敗の有無
・制限時間
・カード配布方法

→ 現段階では「どんな遊びが可能か」のアイデアを広げる。
→ その後、共通する最小システムを逆算する。
